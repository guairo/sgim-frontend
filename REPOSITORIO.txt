-------------------------------------------------------------------------------
  HISTORIAL DE COMMITS
-------------------------------------------------------------------------------

Los commits realizados sobre este proyecto pueden revisarse con el comando:

   git log --oneline --graph --decorate

Cada commit corresponde a una iteracion funcional del modulo:
  1. Configuracion inicial del proyecto (Vite + React + Tailwind).
  2. Autenticacion y rutas protegidas.
  3. Layout principal y navegacion.
  4. Servicios y datos semilla del modulo de Bienes.
  5. Listado de bienes con filtros.
  6. Formulario de creacion y edicion.
  7. Ficha de detalle y eliminacion con confirmacion.
  8. Documentacion y README.
